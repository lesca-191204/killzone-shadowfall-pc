## 🛡️ God mode without hit effects (new)

*Launcher → Cheats · or Insert → Cheats*

Before, god mode kept you alive but the game still played every hit: the screen turned red, hit
markers showed up and the camera shook. Now, with **God mode** on, **hits no longer reach you at
all**. Enemies still take damage normally, and turning it off brings everything back at once.

## 🚀 Faster GPU threads (new, on by default)

A new lock system for the graphics threads, contributed by **clearfeather** (PR #96). On our test
PC, with the same scene:

| | Before | 0.7.0 |
|---|---|---|
| Draw calls per second | 114.8k | **158.1k (+38%)** |
| Frames slower than 40 ms | 203 | **119 (−41%)** |

If something looks wrong, turn it off in *Launcher → Advanced → Performance → **Fast synchronization between game threads***.

## 🌍 Game language (new)

*Launcher → Advanced → Game → **Game language***

Choose any language **your copy includes** (the list comes from your dump). **Automatic** uses the
Windows language if your copy has it, otherwise English. This also helps **European copies**: pick
your copy's language there.

> ℹ️ **The game saves the language in its profile.** If you already have a profile, it keeps its
> language: the new choice applies to a **new profile**.

## ⌨️ Controls

*Launcher → Controls → Keyboard and mouse*

| | |
|---|---|
| 🚶 **Movement** | **Forward / back / left / right can be remapped** (numpad, arrows, ESDF…) |
| 👆 **Touchpad swipes** | Put each **swipe direction (OWL orders) on its own key** |
| 🎮 **Menu shortcut** | Choose the controller shortcut for the in-game menu: **L2+R3, L3+R3, Share+Options** or none |
| 📝 **Button descriptions** | Each button now says what it does in the game (jump, melee, OWL…) |

## ⏱️ FPS limit and frame pacing

- If you start the game **with 144 / 240 / unlimited**, the limit in *Insert* now **changes live**.
- The frame limiter and presentation now use **high-resolution timers**: frames arrive on time
  instead of up to 8-15 ms late. Smoother at any limit.

## 🎬 Upscaling in cutscenes

**DLSS, FSR 3.1 and FSR 4** used to stop working in frames without HUD (cutscenes, the prologue):
the image looked pixelated and shaky. Now they upscale every frame.

## 🧰 Launcher

- 🖱️ **Desktop shortcut** that starts the game **without the launcher** (*Advanced → Launcher*), and
  `--play` for Steam and other launchers.
- 🎨 **ReShade** section (*Advanced → ReShade*): shows if it's installed and opens the folder. Install
  ReShade on `bin\KillzoneShadowFall.exe` with the **Vulkan** API.
- ⚡ **"Preparing shaders" is faster** on slow disks: the cache is read ahead in several threads.
- 🔄 **Updates from 0.6.0 fixed** (#87): this one installs itself correctly.
- 🛟 If the new launcher stays **black**, it switches to the classic one by itself and starts without
  GPU acceleration next time.

## 🛡️ Modo dios sin efectos de golpe (nuevo)

*Launcher → Trucos · o Insert → Cheats*

Antes, el modo dios te mantenía vivo pero el juego igual mostraba cada golpe: la pantalla se ponía
roja, aparecían las marcas de golpe y la cámara se sacudía. Ahora, con el **Modo dios** activado,
**los golpes directamente no te llegan**. Los enemigos reciben daño normal, y al desactivarlo todo
vuelve al instante.

## 🚀 Hilos de GPU más rápidos (nuevo, activado por defecto)

Un sistema de bloqueos nuevo para los hilos gráficos, aportado por **clearfeather** (PR #96). En
nuestra PC de prueba, con la misma escena:

| | Antes | 0.7.0 |
|---|---|---|
| Dibujos por segundo | 114.8k | **158.1k (+38%)** |
| Cuadros de más de 40 ms | 203 | **119 (−41%)** |

Si algo se ve mal, desactivalo en *Launcher → Avanzado → Rendimiento → **Sincronización rápida entre hilos del juego***.

## 🌍 Idioma del juego (nuevo)

*Launcher → Avanzado → Juego → **Idioma del juego***

Elegí cualquier idioma **que traiga tu copia** (la lista sale de tu dump). **Automático** usa el
idioma de Windows si tu copia lo tiene; si no, inglés. Sirve también para las **copias europeas**:
elegí ahí el idioma de tu copia.

> ℹ️ **El juego guarda el idioma en su perfil.** Si ya tenés un perfil, conserva su idioma: la
> elección nueva se aplica a un **perfil nuevo**.
