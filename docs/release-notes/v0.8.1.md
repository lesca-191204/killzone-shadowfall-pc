## 🎞️ Smoother frame generation (#106)

With V-Sync off, the port presented in a mode (Mailbox) that replaces a waiting frame with the next
one: the generated frame, sent half a frame before the game's own, was often **never shown**, and that
mode also kept **G-Sync / FreeSync** from pacing the frames. That's why frame generation could show
more FPS and still feel less smooth than without it.

- With frame generation on, the port now presents in **Immediate** mode: every frame is shown and
  G-Sync / FreeSync can work.
- The game's own frame rate is **capped by itself** so that its frames plus the generated ones stay
  just under your monitor's refresh rate (as Reflex does with DLSS Frame Generation). For example:
  165 Hz → about 78 game FPS → about 156 FPS on screen; 144 Hz → about 69 → about 138.

## 🛡️ God mode (#110)

The "no hit effects" part of god mode (added in 0.7.0) took any character with a controller for the
player, and AI soldiers have one too, so **everyone** became immortal. It now recognises the local
player exactly as the game itself does.

## 🔴 AMD: FSR / frame generation crash (#102, #107)

On RX 6600 / 6600 XT the GPU was lost the moment FSR 3.1 started working on the scene (native picture
worked). FSR 3.1 now uses its **32-bit shader set on AMD cards** instead of the 16-bit one. We can't
test it on that hardware ourselves: if it still crashes, please report it with your logs.
(`GOW3_FSR_FP16=1` brings the old behaviour back.)

## ⌨️ Numpad keys (#103)

In the classic launcher, with NumLock on, the numpad digits were read as the top-row numbers. They're
now told apart ("Keypad 8"), so both can be bound to different actions. The main launcher already
told them apart.

## 🌐 Multiplayer page

The **"Choose…"** button for the friend's **Host-connection** file did nothing in the new launcher
(only the classic one worked). Fixed.

## 🎞️ Generación de cuadros más fluida (#106)

Con el V-Sync apagado, el port presentaba en un modo (Mailbox) que reemplaza un cuadro en espera por el
siguiente: el cuadro generado, enviado medio cuadro antes que el del juego, muchas veces **no llegaba a
verse**, y además ese modo no dejaba que **G-Sync / FreeSync** ordenara los cuadros. Por eso la
generación de cuadros podía marcar más FPS y aun así sentirse menos fluida que sin ella.

- Con la generación de cuadros activada, el port ahora presenta en modo **Immediate**: se muestran
  todos los cuadros y G-Sync / FreeSync puede funcionar.
- Los FPS propios del juego se **limitan solos** para que, sumados a los generados, queden justo
  debajo de los Hz de tu monitor (como hace Reflex con la generación de cuadros de DLSS). Por ejemplo:
  165 Hz → unos 78 FPS de juego → unos 156 en pantalla; 144 Hz → unos 69 → unos 138.

## 🛡️ Modo dios (#110)

La parte "sin efectos de golpe" del modo dios (de la 0.7.0) tomaba como jugador a cualquier personaje
con controlador, y los soldados con IA también tienen uno, así que **todos** se volvían inmortales.
Ahora reconoce al jugador local igual que lo hace el propio juego.

## 🔴 AMD: crash con FSR / generación de cuadros (#102, #107)

En RX 6600 / 6600 XT la GPU se perdía apenas FSR 3.1 empezaba a trabajar sobre la escena (con imagen
nativa funcionaba). Ahora FSR 3.1 usa sus **shaders de 32 bits en placas AMD** en vez de los de 16 bits.
No lo podemos probar en ese hardware: si sigue fallando, reportalo con tus logs.
(`GOW3_FSR_FP16=1` vuelve al comportamiento anterior.)

## ⌨️ Teclado numérico (#103)

En el launcher clásico, con NumLock activado, los números del teclado numérico se leían como los de
arriba de las letras. Ahora se distinguen ("Keypad 8"), así que se pueden asignar a acciones distintas.
El launcher principal ya los distinguía.
